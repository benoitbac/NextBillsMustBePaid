# Contribuer à NextBillsMustBePaid

Merci de prendre le temps de contribuer ! 🙌

## Workflow

1. **Fork** puis crée une branche depuis `main`.
2. Nom de branche descriptif : `feat/…`, `fix/…`, `docs/…`, `chore/…`.
3. Fais ta modif, commits **atomiques** et ciblés.
4. Ouvre une **Pull Request** décrivant le *quoi* et le *pourquoi*.

## Convention de commit

[Conventional Commits](https://www.conventionalcommits.org/) :

```
feat: ajoute la page X
fix: corrige le calcul Y
docs: met à jour le README
chore: bump des dépendances
refactor: simplifie le module Z
```

## Style de code

- Reste cohérent avec le code environnant.
- Commentaires seulement quand le *pourquoi* n'est pas évident.
- Lance le linter/formatter (une fois configuré) avant de pousser.
