# Décisions techniques (ADR)

Un **ADR** (Architecture Decision Record) documente une décision technique
importante : le contexte, l'option retenue, et le pourquoi.

- Un fichier par décision : `NNNN-titre-court.md` (numérotation croissante).
- Statut : `proposé` → `accepté` → (éventuellement) `remplacé par NNNN`.
- Voir le modèle : [`0001-record-architecture-decisions.md`](0001-record-architecture-decisions.md).

| ---- | --------------------------------- | ------- |

| 0002 | Noyau de simulation déterministe, pas de physique dans la boucle | accepté |
| 0003 | Web d'abord (TypeScript + Vite + three.js) plutôt qu'un moteur | accepté |
